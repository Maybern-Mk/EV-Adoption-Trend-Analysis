# EV Adoption Trend Analysis (Power BI)

## Overview  
This Power BI project analyzes Electric Vehicle (EV) adoption trends across regions and time periods to understand the growth of EV usage and the factors influencing adoption.  

The dashboard provides clear, interactive insights for policymakers, analysts, and sustainability-focused stakeholders to monitor progress toward cleaner transportation.

---

## Objectives  
- Analyze EV adoption growth over time  
- Compare adoption across states and regions  
- Identify high-growth and low-growth areas  
- Present trends in a clear, decision-friendly format  
- Enable interactive exploration using Power BI filters and slicers  

---

## Tools and Technologies  
- **Power BI**  
- **Power Query** for data cleaning and transformation  
- **DAX** for calculated measures and KPIs  
- **CSV / Structured datasets**

## Dashboard Features  

### Key Metrics  
- Total EV registrations  
- Year-over-year adoption growth  
- State-wise EV penetration  
- Average growth rate  

### Visualizations  
- Line charts showing EV adoption trends over time  
- Bar charts comparing state-wise EV registrations  
- Geographic and categorical comparisons  

### Filters and Interactivity  
- Year  
- State or region  
- EV category (if applicable)  

---

## Key Insights  
- EV adoption demonstrates a consistent upward trend, particularly in urbanized regions  
- Certain states lead adoption due to stronger infrastructure and policy support  
- Growth accelerates following major policy or awareness milestones  
- Regional disparities highlight opportunities for targeted interventions
