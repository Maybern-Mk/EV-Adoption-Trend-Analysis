⚡ EV Adoption Trend Analysis (Power BI)
📌 Project Overview

This Power BI project analyzes Electric Vehicle (EV) adoption trends across regions and time periods to understand how EV usage is growing and what factors influence adoption.

The dashboard provides clear, interactive insights for policymakers, analysts, and sustainability-focused stakeholders to track progress toward cleaner transportation.

🎯 Objectives

Analyze EV adoption growth over time

Compare adoption across states / regions

Identify high-growth and low-growth areas

Visualize trends in a clear, decision-friendly format

Enable interactive exploration using Power BI filters and slicers

🛠️ Tools & Technologies

Power BI

Power Query (data cleaning & transformation)

DAX (calculated measures & KPIs)

CSV / Structured datasets

🔍 Key Insights

EV adoption shows a consistent upward trend, especially in urbanized regions

Certain states lead adoption due to infrastructure and policy support

Growth accelerates significantly after key policy or awareness milestones

Regional disparity highlights scope for targeted intervention
